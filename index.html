一、奢侈品回收赛道（2个）
01
全国连锁 · 矩阵化

全国连锁奢侈品回收品牌 · 矩阵化运营

多城市布点品牌，从零散各自为战到统一矩阵与可复制获客SOP。

▾
S 背景

某全国连锁奢侈品回收品牌，多城市布点、统一品牌；平台入驻无二奢类目，且各门店各自为战、内容零散，线上估价咨询流失严重，缺乏统一话术与转化路径。

T 职责

负责品牌小红书矩阵策略，统筹内容规划、自然流SEO、聚光投放与私信转化，并产出门店可复制的执行SOP。

A 动作
  • 账号矩阵分层：搭建"总部品牌号 + 城市门店号"两级矩阵，统一视觉模板、昵称规范与私信话术，避免多门店内容重复内耗。
  • 内容体系：围绕"大牌包款回收估价 / 行情科普 / 避坑指南 / 到店流程"四大选题，输出实拍包款行情、回收价目科普、鉴定小知识等图文内容。
  • 自然流SEO：标题与正文布局"城市 + 回收 + 品牌/包款名"搜索词，优化收藏与咨询引导，承接主动搜索的高意向用户。
  • 聚光投放：定向高消费城市与25–45岁人群，小预算多素材测款，关停低效计划，持续压低单条私信成本。
  • 转化打通：私信标准化估价话术，先确认所在城市再引导就近门店到店，线上线索分发到对应门店承接。
  • SOP沉淀：输出选题库、发布节奏、私信话术与门店执行手册，供各门店照做。
R 结果
  • 建成矩阵账号144个，单账号月均有效估价咨询140+；
  • 通过素材迭代与人群优化，单条私信成本下降约40%；
  • 单账号线上引导到店70/月，形成可复制到新城市门店的获客SOP。
02
北京单店 · 视频转型

北京独立小型回收店 · 图文转视频打造鉴定师口碑

几乎零付费预算，跑通"笔记曝光→私信咨询→到店成交"同城闭环。

▾
S 背景

北京一家独立小型二手奢侈品回收店，单店经营、预算有限、无专职团队；原有账号以图文为主、权重偏低，缺乏专业口碑，客源长期依赖熟人转介绍。

T 职责

更改现有账号的运营模式，由图文变为视频，打造鉴定师的口碑，在几乎零付费预算下跑通"笔记曝光→私信咨询→到店成交"的同城获客闭环。

A 动作
  • 模式转型：账号内容由图文转为短视频，围绕鉴定师实拍鉴定过程、包款成色鉴别、估价区间科普持续更新。
  • 鉴定师口碑：突出鉴定师专业出镜与真实鉴定场景，建立"懂行、靠谱、无套路、不压价"的信任人设。
  • 自然流为主：重点吃北京同城搜索与推荐流量，不做大额投放，把预算压到最低。
  • 私信一对一：用标准化又不失温度的报价话术建立信任，引导到店看实物成交。
  • 老客裂变：引导成交客户发体验好评，沉淀口碑内容反哺账号。
R 结果
  • 3个月恢复账号权重和视频曝光量，月均私信咨询70+；
  • 产出12条爆款内容，单条带来咨询20+；
  • 在近乎零付费成本下跑通单店同城获客，验证小体量门店的可落地打法。
二、精神心理医疗赛道（4个）
03
成都 · 南方

成都 · 受限受理范围下的口碑与复诊运营

不接未成年 / 60+ / 产后抑郁 / 婚恋情感，靠客服精细化维护高复诊率，KOS矩阵 + 聚光获客。

▾
S 背景

成都某精神心理专科医院，不接未成年（未成年独立看诊不计入客资）、不接60岁以上人群，不接产后抑郁、恋爱婚姻情感类；

平台竞对以私立为主、口碑较好、受理范围广；本院公立多点医生同时也在竞对医院接诊。

本院优势在于客服后期维护到位、复诊率高；负面评价虽时有出现，需要及时响应处理。

T 职责

在受限合理范围内搭建本地内容与KOS员工号矩阵，企业号与员工号配合聚光投流，获取精准成人咨询并维护线上口碑。

A 动作
  • 合规选题：只做成人焦虑、失眠、职场情绪等本院可接方向，主动规避未成年、60+、产后抑郁、婚恋情感等不受理词，减少无效客资。
  • KOS员工号：打造医生助理号、公立医生个人号，由个人号引流到私立多点坐诊，再引导至所负责的项目医院就诊。
  • 企业号 + 员工号配合聚光投流：企业号承接品牌背书，医生助理 / 医生员工号做人设信任，两套账号协同投放聚光；定向成都本地成人人群，小预算多素材测款、优化出价、管控单条留资成本，持续关停低效计划。
  • 口碑与复诊：私域由客服精细化后期维护、提升复诊率；对负面评价及时响应处理，降低扩散影响。
  • 本地SEO：布局成都本地可接方向搜索词，承接主动咨询。
R 结果
  • 月均留资由个位数增长到最高203，有效率最高达到51.22%；到诊由个位数增长到65，二转率最高达到58.82%；
  • 在受限合理范围内沉淀稳定可接客资基本盘，复诊率与口碑维护形成正向循环，到诊结果不再以老客复诊为主。
04
重庆 · 南方

重庆 · 服务差异化破局 + 多平台统一口碑

本院规模小、设施老旧，竞对以公立为主；以服务和多渠道联动取胜，主做产后抑郁 / 婚恋情感。

▾
S 背景

重庆某精神心理专科医院，本院名气主要来自其他科室，本院规模小、设施较老旧，距成都较近；平台竞对以公立为主、竞争力强。本院以产后抑郁、恋爱婚姻情感为主要方向，不独立接诊青少年，家长陪同情况下可接待。

T 职责

避开硬拼公立名气，以服务差异化破局，联动其他平台渠道统一主推口碑，企业号与员工号配合聚光，获取本地精准咨询。

A 动作
  • 服务差异化：主打贴心服务、就诊流程透明、响应及时，用体验感弥补规模与硬件短板。
  • 多平台联动：联合大众、爱医医、抖音、公众号等渠道，与小红书内容统一主推口碑、互相导流。
  • 定向选题：以产后抑郁、恋爱婚姻情感为主线；青少年仅在家长陪同下承接，表述保持合规。
  • KOS员工号：打造医生 / 咨询师个人号做人设信任，企业号做品牌背书，企业号与员工号配合聚光定向重庆本地。
  • 在地化与搜索：输出重庆场景化就医指南，布局本地关键词承接主动搜索。
R 结果
  • 留资成本和到诊成本下降约60%；多渠道统一口碑落地，到店前咨询顾虑明显减少；
  • 月均留资由二十几增长到最高156，有效率最高达到47.35%；到诊由十几增长到55，二转率最高达到42.71%。
05
沈阳 · 北方

沈阳 · 传统渠道转线上、KOS矩阵打造本院医生口碑

原依赖百度投放 / 公众号，小红书基础弱；只推本院医生，AI斯坦福机器人设备做主推。

▾
S 背景

沈阳某医院主要依赖传统渠道（百度投放、公众号），抖音与小红书比较薄弱；公立多点医生不配合推广，只能主推本院医生；不接青少年独自就诊。本院有特色技术——AI斯坦福机器人设备，可作为主推亮点。单渠道预算有限的情况下，公众号在小红书平台推广引流并相互配合。

T 职责

从0搭建小红书，配合KOS员工号矩阵打造本院医生口碑，以特色设备为卖点，企业号与员工号配合聚光，并带教本地团队。

A 动作
  • 渠道转型：把传统百度 / 公众号经验迁移到小红书，公众号内容在小红书合规引流、相互打配合。
  • KOS矩阵：围绕本院医生打造员工号矩阵（公立多点医生不配合，只推本院医生），统一人设与内容口径。
  • 特色卖点：以AI斯坦福机器人设备为主推内容，做科普与体验感差异化。
  • 合规边界：不接青少年独自就诊，选题主动规避对应表述。
  • 聚光与带教：企业号 + 员工号配合聚光小额测试再放量；搭建标准化选题库与SOP，带教本地团队独立产出。
R 结果
  • 月均留资由个位数增长到最高317，有效率最高达到66.67%；到诊由个位数增长到最高144，二转率最高达到62.39%；
  • 完成账号0→1起号并通过合规备案，本地团队可按SOP独立产出内容与承接咨询，不再依赖专人盯守。
06
天津 · 北方

天津 · 医院+机构双线程 · 矩阵+投放+达人+私域全链路

开药 / 重症导医院，轻咨询导下属机构；医生 + 咨询师双推，企业号 + 员工号配合聚光。

▾
S 背景

天津采用医院 + 机构双线程运营：需要开药 / 症状较重的引导到医院就诊，轻需求 / 只做咨询的引导到下属机构做咨询；医生 + 咨询师双推。无公立多点医生配合，主推本院医生；需贴合平台严打规则，以恋爱婚姻情感咨询为明线，谨慎处理抑郁、焦虑等敏感病种表述以避免限流。

T 职责

统筹企业号 + KOS员工号矩阵、自然流内容、聚光投放、达人 / 素人合作与微信私域承接全链路，对有效咨询量与到诊 / 到店转化率负责。

A 动作
  • 双线程分流：按需求轻重把线索分别导向医院（开药 / 症状重）与下属机构（轻咨询），医生与咨询师双线推荐、分别承接。
  • 矩阵搭建：搭建"企业官方号 + 本院医生 / 咨询师KOS员工号"体系，统筹员工号开通、人设包装、内容分发与日常管理；完成医疗类目合规备案与内容审核。
  • 企业号 + 员工号配合聚光：企业号做品牌背书，员工号做人设信任，两套账号协同投聚光，定向天津本地需求人群，优化人群、素材与出价、管控单客成本。
  • 合规选题：以恋爱婚姻情感咨询为主线规划内容，抑郁 / 焦虑等敏感病种词谨慎表述，规避平台严打限流。
  • 达人 & 素人种草：蒲公英联动本地生活达人与心理垂直KOC输出真实体验，统筹素人小白号铺量营造口碑。
  • 私域闭环：评论引导→私信→微信分层承接，按需求类型分流到医院或机构，提升转化。
R 结果
  • 医院方面月均留资最高226，到诊最高105；
  • 机构方面月均留资最高448，到诊最高210；
  • 形成内容、投放、达人、私域相互配合的稳定获客体系。

经验沉淀

以下为可复用的个人方法沉淀，面试中可直接展开讲。

内容方向
  • 痛点科普 / 本地信任 / 行情估价 / 就医指南 等中心选题
  • 痛点选题—结构化正文—收藏/咨询引导三段式
聚光投放
  • 建计划→小预算测素材→关停低效→加码高转化
  • 只盯CTR、CPC、单线索成本、到店/到诊转化
  • 素材定期更新防止衰退
达人 & 素人
  • 少量头部背书 + 本地KOC/KOL + 素人小白号铺量
  • 二奢不虚构高价回收、医疗不承诺疗效
  • 平台官方充值结算 + 按笔记发布量、互动量机构结算
私域闭环
  • 笔记曝光→评论答疑→私信→微信分层→预约
  • 按需求类型/紧急度打标签分层推送，不群发骚扰、跟进未回复线索
  • 回收行业维护老客二次成交，医疗行业定期回访
